## PLANR 0.5.2 — an ExoSynk Labs project

### 📅 Official release: 5 December 2026
PLANR launches on **Google Play** and **F-Droid** on **5 December 2026**. Until then, this release is the newest build to install from GitHub.

### New
- **About PLANR** shows the official release date.
- **Full releases:** GitHub releases are now full releases (no longer pre-releases), so "Latest release" and direct download links always point to the newest PLANR.

### Repository
- New README with download badges, store buttons for the 5 December launch, and the ExoSynk family (XPENC, FITNS, CONECTR).
- Added CODE_OF_CONDUCT.md, SECURITY.md, PRIVACY.md, CHANGELOG.md, issue forms, and docs for features, development and the planned ExoSynk Link.

### Install
Download `PLANR-0.5.2.apk` below (Android 11+). Then open **Alarm → Alarm setup**, allow each item, and run **Test alarm**.
