## PLANR 0.5.3 — an ExoSynk Labs project

### 📅 Official release: 5 December 2026

### Off-Grid is now really locked
- **No more navigation buttons.** The Off-Grid lock screen is now true full screen. Back, Home and Recents can't take you out, even for a second, and the quick-settings shade can't be pulled down while the lock screen is showing.
- **Calls come through properly.** An incoming call is never pushed back to the lock screen, whichever phone brand's call screen you have. Allow **phone access** on the Off-Grid screen and the call opens full screen straight away, like it normally does.

### Fixes
- **Repeating reminders keep alerting** even if you didn't tick one off: they move to their next date and remind you again.

### Signed with the ExoSynk Labs key
From this version, PLANR is signed with its permanent release key, so future updates install over it.
**One time only:** builds up to 0.5.2 used temporary keys. Export a backup (**Settings → Backup & restore → Export**), uninstall the old PLANR, install this one, and restore.
